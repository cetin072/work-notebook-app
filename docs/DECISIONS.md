# Decisions Log

## 2026-09-11

### D-001 — 상용화 앱은 별도 저장소에서 개발

- 기존 실사용 웹앱: `cetin072/worklog-voice-pwa`
- 상용화 Android 앱: `cetin072/work-notebook-app`
- 기존 웹앱은 안정판으로 계속 사용한다.

### D-002 — Local-first

로컬 데이터가 기본 Source of Truth다. 외부 서비스는 선택적 확장 기능이다.

### D-003 — 초기 Beta는 계정 없이 사용

최초 설치 시 로그인, Notion, AI 연결을 요구하지 않는다.

### D-004 — 초기 기록 모델

기본 기록은 제목, 내용, 날짜, 시간, 완료 여부, 사진, 음성, 생성시간을 지원한다.

### D-005 — 사진 기능 V1

첫 버전은 사진 저장/첨부까지만 구현한다. OCR·요약·일정 자동추출은 Smart 단계로 미룬다.

### D-006 — 위젯 우선

대표 홈 화면 위젯은 4×2로 시작하며 오늘 미완료 업무 최대 3개와 음성/사진 빠른 실행을 제공한다.

### D-007 — AI는 공급자 중립적 개념

제품 UI에서는 `ChatGPT 연결`이 아니라 `AI 연결`을 사용한다. 초기에는 Android 공유 기반 `내 AI로 보내기`를 우선 검토한다.

### D-008 — Android 네이티브 우선

초기 기술 방향은 Kotlin + Jetpack Compose + Room을 기본 권장안으로 한다. 실제 구현 시작 전 프로젝트 템플릿/최소 SDK 등 세부사항을 확정한다.
