# Beta 2 Scope

## 목표

첫 Android Beta는 **인터넷이 없어도 휴대폰에 업무를 기록하고 다시 볼 수 있는 로컬 업무수첩**을 완성한다.

## V1 포함 범위

기록 1건의 기본 필드:
- 제목
- 내용
- 날짜
- 시간
- 완료 여부
- 사진
- 음성
- 생성시간

주요 기능:
- 직접 입력
- 음성 메모 저장
- 사진 촬영/첨부
- 오늘 할 일 표시
- 오늘 기록 표시
- 완료/미완료 전환
- 로컬 데이터 저장
- 앱 재실행 후 데이터 유지
- 인터넷이 없어도 기본 기능 사용 가능

## 우선 개발 순서

1. Android 앱 기본 셸
2. Room/SQLite 기반 로컬 저장
3. 업무 1건 생성/조회/수정/완료
4. 오늘 화면
5. 음성 메모 저장
6. 사진 촬영/첨부
7. 4×2 홈 화면 위젯
8. 실기기 베타 테스트

## V1에서 제외

- AI 자동 정리
- OCR 자동 추출
- 일정 자동 생성
- Notion 동기화
- Google/Samsung Calendar 동기화
- 회원가입/로그인
- 서버 DB
- 다중 기기 동기화
- 유료 AI API

이 항목들은 기본 로컬판이 안정된 뒤 단계적으로 추가한다.
