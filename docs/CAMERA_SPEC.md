# Camera / Document Capture Spec

## Beta 2 V1

초기 버전은 단순하게 한다.

- 사진 촬영
- 기존 사진 첨부
- 업무 기록 1건에 사진 연결
- 촬영 후 제목/날짜를 사용자가 직접 입력 가능
- 사진 원본을 로컬에 보관

## V1에서 하지 않는 것

- OCR 자동 인식
- 문서 요약
- 날짜/시간 자동 추출
- 일정 자동 생성
- AI 자동 분류

## 추후 Smart 단계

향후에는 다음 흐름을 목표로 한다.

```text
문서 촬영
→ OCR
→ 날짜/시간/장소/할 일 추출
→ 내용 요약
→ 사용자 확인
→ 업무/일정으로 저장
```

자동 추출 결과는 바로 확정하지 않고 사용자 확인 단계를 둔다. 원본 이미지는 보존한다.
