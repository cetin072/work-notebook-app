# Widget Spec

## 대표 위젯 V1

우선순위는 **4×2 위젯 1종**이다.

예시:

```text
┌─────────────────────────────┐
│ 업무수첩 · 오늘              │
│ ① 오늘 할 일 1              │
│ ② 오늘 할 일 2              │
│ ③ 오늘 할 일 3              │
│                             │
│   🎙 기록       📷 촬영      │
└─────────────────────────────┘
```

## 표시 규칙

- 오늘 날짜의 미완료 업무를 우선 표시한다.
- 최대 3개 표시한다.
- 더 있으면 `+ N개 더` 표시를 검토한다.
- 인터넷 없이 로컬 DB만으로 표시되어야 한다.

## 동작

- 업무 행 탭 → 해당 업무 상세화면
- 제목/빈 영역 탭 → 오늘 화면
- `🎙 기록` → 음성 기록 시작 화면
- `📷 촬영` → 카메라/문서 촬영 시작

## 후순위

- 2×1 초고속 기록 위젯
- 2×2 최근 기록 위젯
- AI 브리핑 표시
- 새로고침/동기화 상태

V1에서는 기능 수보다 즉시성·안정성을 우선한다.
