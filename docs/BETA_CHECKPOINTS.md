# Beta 체크포인트 운영

개발 중 모든 커밋을 휴대폰에 직접 설치해 확인하지 않는다.

## 자동 검수

다음은 GitHub Actions와 코드 검수로 우선 확인한다.

- 컴파일
- 단위 테스트
- Room 스키마 처리
- debug APK 빌드
- release AAB 빌드

## 실기기 확인이 필요한 기능

다음은 의미 있는 Beta 체크포인트에서 묶어서 확인한다.

- 마이크/음성인식
- 홈 화면 위젯
- 카메라
- 사진 표시
- 실제 앱 업데이트 후 로컬 데이터 유지

## 현재 체크포인트

### Beta 0.2 후보

- 로컬 업무 저장/조회/수정/완료
- 음성 기록
- 4×2 오늘 업무 위젯
- 카메라 사진 기록
- 로컬 오늘 브리핑

이 기능 묶음이 CI GREEN 상태가 되면 Google Play 내부테스트 배포 준비를 진행한다.

## 원칙

현재 실사용 웹 `worklog-voice-pwa`는 새 Android Beta가 안정화될 때까지 그대로 유지한다.
