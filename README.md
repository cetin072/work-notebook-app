# 업무수첩 Android App

상용화용 **Local-first 개인 업무수첩** 개발 저장소입니다.

현재 실사용 웹앱 `cetin072/worklog-voice-pwa`와 분리하여 개발합니다.

## 현재 목표

인터넷·로그인·Notion·AI 없이도 Android 휴대폰에서 업무를 기록하고 다시 볼 수 있는 Local MVP를 만든다.
